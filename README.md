# QQQ Volatility Confidence Intervals

## Run locally

1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the app:

   ```bash
   streamlit run app.py
   ```

Streamlit will print a local URL (usually http://localhost:8501) to open in your browser.

## Deploy online

Push `app.py` and `requirements.txt` to a GitHub repository, then create an app on Streamlit Community Cloud and select that repository and `app.py`.
